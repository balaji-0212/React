# Task 5 - Form with Validation

A responsive React form built with functional components and `useState` validation only.

## Features

- Blank profile fields with resume-based placeholders for Balaji Sivakumar.
- Inline validation for required values, email, phone, password strength, matching passwords, zip code, address, city, and comma separated skills.
- Disabled submit button until the form is valid.
- Password visibility toggles, address character counter, reset button, and success message.

## Run Locally

```bash
npm install
npm start
```
