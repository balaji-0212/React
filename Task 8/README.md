# Task 8 - Form using useContext & Theme Toggle

This React app demonstrates a professional resume details form powered by the `useContext` hook. Form data, theme state, and the theme toggle action are shared through a single context provider to avoid prop drilling.

## Features

- React Context API with `createContext` and `useContext`
- Nested component structure: `App` -> `Form` -> `InputFields`
- Resume details loaded as default form values
- Fully editable controlled form fields
- Light and dark theme toggle
- Responsive professional UI with transitions, shadows, and polished form controls

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
