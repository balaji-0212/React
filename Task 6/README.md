# Task 6 - Fetch Data from API

Modern React application for fetching and presenting user data from the JSONPlaceholder public API.

## Features

- Fetches users from `https://jsonplaceholder.typicode.com/users`
- Uses `useEffect` and `useState`
- Loading and error states
- Responsive card layout
- Portfolio-style navbar, hero, about section, and footer
