# Mini Chat Application

A professional mini chat application built with React.js, functional components, and the `useState` hook.

## Features

- Type and send chat messages
- Send messages with the button or Enter key
- Empty message validation
- Messages render instantly in the order sent
- Input clears automatically after sending
- Auto-scrolling message area
- Message timestamps
- Responsive modern UI

## Local Development

```bash
npm install
npm run dev
```
