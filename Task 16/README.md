# Career Growth Hub

Career Growth Hub is a production-style React application for professionals who want one focused place to manage learning plans, project proof, job targets, profile details, and progress insights.

## Features

- Responsive dashboard with nested overview and analytics views
- API-powered learning resource explorer with search, filters, loading states, and error handling
- Job explorer with dynamic detail pages
- Project portfolio CRUD with validation and local storage persistence
- Profile management with editable professional details
- Settings center with theme, notification, and goal preferences
- Shared navigation, cards, tables, forms, modals, and status components
- Global state managed with Context and Reducer
- Custom hooks for local storage and remote data fetching

## Tech Stack

- React
- Vite
- React Router DOM
- Lucide React
- CSS modules via standard CSS architecture
- Browser local storage

## Setup

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash

```
