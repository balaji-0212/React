# Task 7 - Profile Image Upload Card

Responsive React mini project that displays a professional profile card for Balaji Sivakumar with image upload, live preview, like toggling, and dynamic comments.

## Features

- Profile image upload with instant preview
- `useRef` powered hidden file input
- Like button with dynamic heart color and count
- Controlled comment input with empty comment prevention
- Modern responsive card UI with smooth hover states
- Resume-based profile summary, skills, and links

## Run Locally

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.
